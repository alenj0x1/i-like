# Contrato documental

Adaptar los nombres a la convención existente. Si el repositorio no dispone de ellos, las plantillas proveen un inicio neutral.

| Documento | Contenido mínimo |
| --- | --- |
| `AGENTS.md` | Reglas de trabajo, continuidad, bloqueos y commits. |
| Análisis | Hechos con evidencia, riesgos y propuestas separadas. |
| Tablero | Estado, dependencias, resultados y siguiente paso. |
| Plan | Fases, dependencias, alcance y criterios de cierre. |
| Decisiones | Fecha, estado, contexto, decisión, consecuencias y alternativas. |
| Requisitos | Fuente, prioridad, aceptación y trazabilidad a alcance aprobado. |
| Bitácora | Metadatos, proceso, hallazgos, cambios, validaciones, bloqueos y continuación. |

Actualizar los documentos durante el trabajo, no solo al final. Conservar el historial de tareas y sesiones.
