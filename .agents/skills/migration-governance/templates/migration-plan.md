# Plan de migración

## Principios

- Migrar por capacidades de negocio completas.
- Validar cada fase antes de avanzar.
- Mantener trazabilidad entre alcance, decisiones, requisitos y pruebas.

## Fase 0 — Descubrimiento

**Objetivo:** documentar el comportamiento, riesgos y alcance inicial.

**Criterio de finalización:** inventario, riesgos de datos, alcance y exclusiones aprobados.

## Fases posteriores

Definir objetivos, alcance, dependencias y criterios verificables adaptados al proyecto.
